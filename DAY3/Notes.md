## 📖 Key Concepts

### ✅ Anaconda
- Free Python distribution for Data Science
- Includes Python, Jupyter Notebook, and popular libraries
- Uses Conda for package management
- Simplifies installation and environment management

### ✅ Jupyter Notebook
- Interactive environment for Python programming
- Supports code, Markdown, images, and visualizations
- Executes code one cell at a time
- Ideal for Data Science and Machine Learning projects

### ✅ Google Colab
- Cloud-based Jupyter Notebook by Google
- No installation required
- Free access to GPU and TPU
- Automatically saves notebooks to Google Drive
- Easy collaboration and sharing

### ✅ NumPy
- Library for numerical computing
- Uses fast and memory-efficient arrays
- Supports vectorized mathematical operations
- Provides functions for statistics and linear algebra

### ✅ Pandas
- Library for data analysis and manipulation
- Works with Series and DataFrames
- Supports CSV, Excel, and other file formats
- Used for cleaning, filtering, and analyzing datasets

## 📊 Comparison

| Feature | NumPy | Pandas |
|---------|--------|---------|
| Primary Purpose | Numerical Computing | Data Analysis |
| Data Structure | Array | Series & DataFrame |
| Performance | Very Fast | Fast |
| Best For | Mathematical Operations | Data Manipulation |
| Supports CSV Files | ❌ | ✅ |
| Built-in Statistical Functions | ✅ | ✅ |
| Handles Missing Values | Limited | Excellent |
